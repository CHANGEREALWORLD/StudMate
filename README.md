# StudMate

StudMate is a web-based academic and career organizer that helps students manage daily tasks, subjects, and study planning in one place.

## Features
- Daily task planner  
- Subject-wise planning  
- Career guidance pages  
- Firebase authentication & database  

## Tech Stack
- HTML, CSS, JavaScript  
- Firebase (Auth, Firestore, FCM)

## Status
In active development

## Setup
1. Open `index.html` in a browser  
2. Configure Firebase for full functionality
